ALLES VERBINDEN

100 % kostenlos, ohne Abo: 13 Kanäle über die offiziellen Gratis-APIs. Ein Klick pro Plattform bringt dich direkt an die richtige Stelle. Häkchen setzen, wenn erledigt (wird nur in diesem Browser gespeichert).

⚡ Ein-Klick-Verbinden (wie bei Metricool)

Klick auf „Verbinden“ → Plattform fragt nach Erlaubnis → „Weiter“ → fertig. Der Direkt-Poster holt sich alles automatisch.

Einmalige Einrichtung (ca. 10 Minuten, danach nie wieder)
  1. Kostenloses Cloudflare-Konto → „Workers & Pages“ einmal öffnen (legt deine workers.dev-Adresse an).
  2. Cloudflare → My Profile → API Tokens → Vorlage „Edit Cloudflare Workers“ → Token kopieren.
  3. GitHub → Settings → Secrets → Actions: CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID und VERBINDER_PASSWORT (selbst ausgedacht, mind. 16 Zeichen).
  4. GitHub → Actions → „Verbinder deployen“ → Run workflow. Danach hier mit dem Passwort anmelden.
  5. Alles Weitere passiert hier auf der Seite: je Plattform der Assistent mit Anleitung, Schlüssel einfügen, Verbinden.

1 · Sofort startklar (2–5 Minuten)
