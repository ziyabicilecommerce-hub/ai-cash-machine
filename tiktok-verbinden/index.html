TikTok verbinden

Einmalig einrichten, damit der kostenlose Direkt-Poster (#99) deine Videos an dein eigenes TikTok-Konto schickt. Alles läuft über die offizielle TikTok-API; Passwörter und Schlüssel bleiben in deinem Browser.

1 · App bei TikTok anlegen (einmalig)

  1. developers.tiktok.com → Login → Manage apps → Connect an app.
  2. Als Website, Datenschutz und Nutzungsbedingungen diese Seiten eintragen (Links unten auf dieser Seite).
  3. Produkte hinzufügen: Login Kit und Content Posting API. Scopes: user.info.basic, video.upload (und später video.publish).
  4. Bei Login Kit als Redirect URI eintragen:
  5. Client Key und Client Secret aus der App kopieren.

4 · In GitHub eintragen

  1. GitHub → Repo ai-cash-machine → Settings → Secrets and variables → Actions.
  2. Secrets: TIKTOK_CLIENT_KEY, TIKTOK_CLIENT_SECRET, TIKTOK_REFRESH_TOKEN.
  3. Fertig: Neue Hochformat-Videos landen als Entwurf in deinem TikTok-Postfach – in der App auf die Benachrichtigung tippen und posten.
  4. Nach bestandenem TikTok-Audit: Variable TIKTOK_MODUS = direkt → Videos gehen automatisch online.
