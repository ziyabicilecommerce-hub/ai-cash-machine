# Nachtwerk original scene illustrations

These six scenes were created specifically for this project with procedural SVG geometry: `corridor`, `forest`, `house`, `stairs`, `window`, and `void`. They contain no stock photography, third-party source images, external fonts, or downloaded visual assets.

The SVG files are the original editable vector artwork. Their corresponding PNG files are raster exports at 1280 × 720, created using the already-installed system librsvg and Cairo libraries. The preview contact sheet is a montage of these originals.

These are **illustrations, not AI-generated live-action video**. Camera movement over these scenes is an illustrated animatic / motion-still effect. They are suitable for the project's free browser preview and export path without an external image or video API.

Recreate the artwork from the original project script: `python local/create_art.py`.

All artwork is original to the Nachtwerk project and may be used and modified with this project. No third-party attribution is required for these images.
